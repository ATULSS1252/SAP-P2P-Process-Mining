# SAP-P2P-Process-Mining
End-to-end purchase-to-pay process mining repository built with Python (PM4Py) and SAP Analytics Cloud. Maps BPI Challenge 2019 event logs (~1.5M events) to standard SAP S/4HANA tables (EKKO, EKPO, EKBE, RSEG, LFA1) to quantify 3-way match compliance, rework loops, and operational bottlenecks.
